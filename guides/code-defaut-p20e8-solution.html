Code P20E8 : "Défaut Moteur : Faites réparer le véhicule"

“Si vous avez ce code sur une Peugeot ou Citroën BlueHDi, vous risquez le 'Démarrage Interdit' dans 1100 km.”

Code P20E8 : Ca veut dire quoi ?

Le code P20E8 signifie "Pression du liquide d'urée trop faible". En clair : votre système antipollution (AdBlue) n'arrive pas à injecter le liquide dans le pot d'échappement.

C'est la maladie n°1 des moteurs 1.5 BlueHDi et 2.0 BlueHDi (Peugeot 208, 308, 3008, Citroën C3, C4 Picasso).

Pourquoi ça arrive ? (Les 3 coupables)

1. La Cristallisation de l'AdBlue (80% des cas)

L'AdBlue sèche et forme des cristaux blancs qui bouchent l'injecteur ou la pompe. C'est comme du calcaire dans une machine à café.

2. Le Réservoir Déformé

Sur certains modèles, le bouchon du réservoir ne laisse pas entrer l'air. Quand la pompe aspire, le réservoir se déforme sous l'effet du vide et casse la pompe.

3. L'Injecteur H.S.

L'injecteur est grippé ou bouché. Moins fréquent mais possible.

Les Solutions : De 20€ à 1200€

🚑 Solution d'urgence : L'effacement du défaut

Pour éviter le blocage "Démarrage Interdit dans XXX km", vous pouvez effacer le code défaut temporairement avec une valise diagnostic.

Cependant, le défaut reviendra si le problème physique n'est pas réglé. Cela vous donne juste du temps pour aller au garage.

👉 Outil recommandé : Mucar CS90 (Permet de lire les codes AdBlue profonds).

✅ Étape 1 : L'additif Anti-Cristallisation

Si la pompe n'est pas encore morte, versez un additif anti-cristallisant dans le réservoir AdBlue. Roulez 500km. Parfois, ça suffit à déboucher le système.

✅ Étape 2 : Le bouchon ventilé

Remplacez votre bouchon bleu par le nouveau modèle ventilé (réf PSA avec valve blanche au centre). Coût : ~15€.

❌ Étape 3 : Le remplacement du réservoir

Si le code P20E8 persiste après effacement + additif, la pompe (intégrée au réservoir) est morte. Coût : 1200€ chez Peugeot (demandez une prise en charge !).
